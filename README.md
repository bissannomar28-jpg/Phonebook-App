# 📞 Phonebook Application

A Python application designed to manage contact records with JSON data persistence.

## 📌 Project Overview
This tool provides a functional command-line interface for managing contact information, allowing users to store, search, and update personal phonebook entries dynamically while persisting data across sessions using JSON.

## 🛠️ Features & Tools
* **Language:** Python
* **Data Storage:** JSON (File Persistence)
* **Key Components:**
  * **Contact Management:** Add, update, and delete contact details.
  * **Search & Lookup:** Search records by name or phone number with input validation.
  * **Persistent Storage:** Automatic reading and writing to JSON files to retain data after exit.
